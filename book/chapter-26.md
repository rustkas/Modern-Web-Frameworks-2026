# Часть VII. Производительность

## Глава 26. Оптимизация JavaScript

К 2026 году парадигма оптимизации JavaScript вышла на принципиально новый технологический уровень благодаря глубокой интеграции инфраструктурных инструментов на базе Rust и окончательному утверждению концепции *ESM-first*. Фокус индустрии сместился с простого уменьшения размера файлов на интеллектуальное управление ресурсами, где цель компилятора — доставить в браузер ровно те байты и строго в тот момент времени, которые необходимы для выполнения текущего сценария пользователя.

---

### Bundling: Эра нативных Rust-сборщиков

Инструменты сборки нового поколения оставили позади медленные JavaScript-решения, обеспечив колоссальный прирост производительности:

* **Bun:** Предлагает встроенный высокопроизводительный бандлер, способный обработать до 10 000 компонентов за доли секунды, выступая одновременно как среда выполнения, менеджер пакетов и инструмент сборки.
* **Rolldown:** Передовой Rust-бандлер, совместимый с API Rollup и предлагающий паритет производительности с esbuild. Он лег в основу экосистемы Vite, гарантируя молниеносную сборку масштабных приложений.
* **Rspack:** Высокопроизводительная альтернатива Webpack, написанная на Rust и сохраняющая полную совместимость с его огромной экосистемой плагинов и лоадеров, что упрощает миграцию legacy-проектов.

---

### Tree Shaking и статический анализ кода

Механизмы очистки кода от балласта стали глубоко интеллектуальными:

* **Tree Shaking:** Современные сборщики (включая Rspack) осуществляют тонкий статический анализ графа зависимостей, автоматически отсекая неиспользуемые экспорты из библиотек.
* **Dead Code Elimination:** В связке с компиляторами уровня *SWC* или *Lightning CSS* инструменты вырезают «мертвые» ветки кода, константы и невызываемые функции, минимизируя итоговый объем клиентских бандлов.

---

### ESM-first и нативная модульность

К 2026 году стандарт ECMAScript Modules (**ESM**) закрепился в статусе фундаментальной основы веб-разработки:

* **Dev Server на ESM:** Инструменты вроде Vite отдают исходные модули браузеру по требованию (*on-demand*), полностью исключая этап долгой предварительной сборки при старте сервера разработки.
* **Современные рантаймы:** Среды Deno и Bun спроектированы вокруг ESM-модели, обеспечивая бесшовное подключение пакетов из реестров и встроенную поддержку TypeScript без транспайлеров.

---

### Dynamic Import и стратегия Code Splitting

Автоматическое разделение кода (*Code Splitting*) интегрировано на уровне самих фреймворков и сборщиков:

* Использование динамических импортов (`import()`) позволяет делить приложение на изолированные чанки, подгружаемые по мере необходимости (*On-demand loading*).
* Этот подход критически важен для достижения целевых показателей **LCP** и **INP**, так как браузер освобождается от необходимости скачивать и парсить гигантские монолитные скрипты при старте.

---

### Import Maps и безъядерная структура

Стандарт **Import Maps** позволяет браузеру напрямую сопоставлять логические имена модулей с их реальными URL без необходимости использования сложных бандлеров на этапе разработки. Это открывает дорогу к архитектурам вида *node_modules-less*, где сторонние зависимости подгружаются напрямую из глобальных кэшей или специализированных CDN-реестров (например, *JSR*), радикально ускоряя инициализацию проектов.

---

### Module Federation: Архитектура микрофронтендов

Технология **Module Federation** стала стандартом де-факто для построения распределенных Enterprise-систем и микрофронтендов:

* Встроенная поддержка на уровне Rspack и Webpack позволяет независимым командам разрабатывать, деплоить и обновлять изолированные части единого интерфейса параллельно.
* Приложения могут динамически обмениваться скомпилированными модулями в runtime, совместно используя общие библиотеки (например, React или дизайн-систему) без дублирования кода в бандлах.

Оптимизация JavaScript в современных реалиях представляет собой слаженную экосистемную оркестрацию, где компиляторы на Rust и нативные возможности браузеров работают в тесном симбиозе для достижения максимального быстродействия.
